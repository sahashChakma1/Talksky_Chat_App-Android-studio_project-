# Talksy - Real-Time Chat Application

![Talksy Logo](https://yourlogo.com)  
A **real-time chat application** built with **Kotlin** and **Firebase**, designed to provide seamless and secure messaging.

## 🚀 Features
- **Real-Time Messaging** - Send and receive messages instantly.
- **User Authentication** - Secure login using Firebase Authentication.
- **Online Status** - See when friends are online.
- **Media Sharing** - Send images, videos, and files.
- **Push Notifications** - Stay updated with new messages.
- **Dark Mode** - Switch between light and dark themes.
- **End-to-End Encryption** - Secure your conversations.

## 🛠️ Tech Stack
- **Frontend**: Kotlin (Android)
- **Backend**: Firebase Firestore (Real-time Database)

- **Storage**: Firebase Storage (Media & Files)

## 📦 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sahashChakma1/Talksky_Chat_App-Android-studio_project-.git
   ```
2. Open the project in **Android Studio**.
3. Connect to **Firebase**:
   - Go to [Firebase Console](https://console.firebase.google.com/).
   - Create a new project.
   - Enable **Authentication**, **Firestore**, and **Storage**.
   - Download `google-services.json` and place it in `app/`.
4. Run the app:
   ```bash
   ./gradlew build && ./gradlew installDebug
   ```

## ⚙️ Configuration
- **Firebase Setup:** Add your Firebase API keys in `google-services.json`.
- **Notifications:** Enable Firebase Cloud Messaging (FCM) in Firebase Console.
- **ProGuard Rules:** If using ProGuard, update `proguard-rules.pro`.
